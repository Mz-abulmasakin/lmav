# LMAV website — Vercel-ready React + Vite project

This folder contains the complete LMAV website, its styles, image assets, React components, and Vercel configuration.

## Run on your computer (Windows CMD)
1. Extract the ZIP file.
2. Open CMD inside the extracted `LMAV_Vercel_Complete` folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.
5. To verify the production build, run `npm run build`.

## Deploy on Vercel
1. Push the complete folder contents to your GitHub repository.
2. In Vercel, import that repository.
3. Use Framework Preset `Vite`, Build Command `npm run build`, and Output Directory `dist`.
4. Deploy. The included `vercel.json` also supplies the Vite build/output settings and SPA route rewrite.
