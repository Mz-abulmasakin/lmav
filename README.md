# LMAV React Website

Responsive React + Vite website for Lauya Movement for APC Victory (LMAV).

## Run locally
1. Extract this project.
2. Run `npm install`.
3. Run `npm run dev`.

## Deploy on Vercel
Import the GitHub repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.
